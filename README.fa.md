[🇬🇧 English](README.md)

## 📐 روش ریاضی

### ماتریس ۲×۲

برای ماتریس:

$$
A =
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$

معکوس ماتریس از رابطه‌ی زیر به دست می‌آید:

$$
A^{-1} =
\frac{1}{ad-bc}
\begin{bmatrix}
d & -b \\
-c & a
\end{bmatrix}
$$

دترمینان ماتریس برابر است با:

$$
\det(A)=ad-bc
$$

اگر دترمینان صفر باشد، ماتریس **تکین (Singular)** است و معکوس ندارد.

---

## 🔢 ماتریس ۳×۳

برای ماتریس ۳×۳، برنامه محاسبات را به چند مرحله تقسیم می‌کند:

```text
ماتریس اصلی
     ↓
ماتریس کهاد
     ↓
ماتریس همسازه
     ↓
ماتریس الحاقی
     ↓
دترمینان
     ↓
ماتریس معکوس
```

فرمول کلی معکوس:


$$
A^{-1} = \frac{\operatorname{adj}(A)}{\det(A)}
$$

که در آن:

* **Minor Matrix** شامل کهادهای ماتریس است.
* **Cofactor Matrix** با اعمال علامت‌های مثبت و منفی مناسب از روی کهادها ساخته می‌شود.
* **Adjugate Matrix** ترانهاده‌ی ماتریس همسازه است.

## ▶️ نحوه استفاده

### ماتریس ۲×۲

برنامه را اجرا کنید:

```bash
python inverse_2x2.py
```

سپس یک ماتریس ۲×۲ وارد کنید، برای مثال:

```text
[[1, 2], [3, 4]]
```

### ماتریس ۳×۳

برنامه را اجرا کنید:

```bash
python inverse_3x3.py
```

برای مثال:

```text
[[1, 2, 3], [0, 1, 4], [5, 6, 0]]
```

معکوس ماتریس در ترمینال نمایش داده خواهد شد.

---

## ⚠️ ماتریس‌های تکین

اگر دترمینان یک ماتریس برابر صفر باشد:

$$
\det(A)=0
$$

آن ماتریس **معکوس ندارد**.

برای مثال:

```text
[[1, 2, 3],
 [2, 4, 6],
 [1, 5, 7]]
```

این ماتریس تکین است، زیرا دترمینان آن برابر صفر است.
